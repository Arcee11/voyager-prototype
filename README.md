# Voyager Prototype

Playable prototype slice of The Voyager, a teen adventure game for The Guided Pathway Foundation, built in Godot 4.7 and exported for the web.

This repo only hosts the exported web build so it can run on GitHub Pages. The Godot source project lives elsewhere (workspace `voyager/prototype/`).

To play: open the GitHub Pages site for this repo. The current build (Pass 6: The First Voyage) is a persistent multi day voyage: shop opening, shipyard, a three day crossing to the Islands of Beginnings on the living chart (12 leagues, lane encounters, a night tally each day), the Lighthouse Keeper's first quest in port, an end screen, and free play sailing afterward. Progress saves on device and the title offers Continue on return.
